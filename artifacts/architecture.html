Practice Server · Technical Brief

예약의 찰나를
안전한 상태로 만든다.

프랜차이즈 공유 연습실의 지점·공간 조회부터 선점, 결제, 예약 확정까지를 다루는 FastAPI 백엔드입니다. 이 문서는 서비스 소개보다 내부 경계와 실패 복구 방식을 중심으로 설명합니다.

정상 결제 시퀀스

클라이언트의 금액은 신뢰하지 않습니다. 선점 스냅샷과 연습실 단가로 서버가 주문 금액을 계산합니다.

시간 선점Redis에서 사용자·공간 슬롯을 원자적으로 잠금
주문 생성시간, 공간, 가격, 만료 시각을 PostgreSQL에 스냅샷
결제 요청PaymentProvider 계약을 통해 외부 상태 생성
승인 이벤트이벤트 ID로 중복을 차단하고 금액·주문 검증
예약 확정DB 슬롯 생성 후 주문을 paid, 결제를 approved로 전환
